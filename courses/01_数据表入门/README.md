## 本课目标

使用 Pandas 创建表格、查看一列、计算平均值。Pandas 是 Python 的表格处理库，代码中用 `pd` 作为简称。

数据是五套虚构房屋，面积单位是平方米，价格单位是万元。
每一行是一套房屋，也叫一个样本；每一列是一种信息。

## 按顺序读代码

```python
df = pd.DataFrame(data)
print(df["面积"])
print(df["面积"].mean())
print(df.shape)
```

- `pd.DataFrame(data)`：把字典转换成表格，DataFrame 是 Pandas 的表格类型。
- `df["面积"]`：取出面积列；`df["价格"]` 取出价格列。
- `.mean()`：求平均值。
- `df.shape`：返回行数与列数。

输出左侧的 0 到 4 是自动生成的行索引，用于标识每一行。
