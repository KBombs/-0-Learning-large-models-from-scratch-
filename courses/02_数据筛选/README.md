## 本课目标

根据条件筛选表格中的行，再对筛选结果做统计。本课仍使用五套虚构房屋。

## 分两步理解筛选

```python
condition = df["面积"] >= 80
large_houses = df[condition]
```

第一行逐个判断面积是否大于等于 80，得到 `False, False, True, True, True`。
第二行保留判断为 `True` 的完整行，留下面积为 80、100、110 平方米的三套房屋。
行索引仍保留原来的编号，不会自动从 0 重新编号。

`df["面积"]` 中的方括号用于选择列，`df[condition]` 中的方括号用于按条件选择行。

## 之前练习的答案

```python
expensive_houses = df[df["价格"] >= 200]
average_area = expensive_houses["面积"].mean()
```

这次把判断与筛选合成一句。筛选价格不低于 200 万元的房屋，然后计算这些房屋的平均面积。

## 已验证结果

- 价格符合条件的房屋有两套，价格分别为 200、220 万元。
- 对应面积为 100、110 平方米。
- 平均面积为 `105.0` 平方米。

记住顺序：比较产生判断结果，筛选保留满足条件的行，统计计算筛选后的数据。
